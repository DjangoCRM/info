# **Soporte**

¿Necesita ayuda con Django CRM?  
Estamos aquí para asegurar que obtenga el máximo de nuestra plataforma. El proyecto CRM ofrece múltiples opciones para obtener asistencia con la configuración, personalización y uso diario.

---

## **Ayuda para Usuarios Finales**

Si es un usuario de CRM y necesita orientación sobre cómo trabajar con el sistema,
visite el [Centro de Ayuda](help/index.md).
Allí encontrará:

* Instrucciones para iniciar sesión y acceder al CRM desde cualquier dispositivo.
* Explicaciones de roles y permisos.
* Guías paso a paso para cada módulo del CRM ([Tareas](features/tasks-app-features.md), [Correo Masivo](features/massmail-app-features.md), [Análisis](features/analytics-app-features.md), etc.).
* Consejos sobre cómo cambiar el idioma de la interfaz y los temas.

El Centro de Ayuda está diseñado para uso diario por gerentes, personal de ventas y otros usuarios de CRM,
mientras que la sección de Soporte se enfoca en la configuración técnica y personalización.

---

## 💬 **Soporte Técnico**

Django CRM es un proyecto impulsado por la comunidad, y el mejor lugar para comenzar es nuestra página de [GitHub Discussions](https://github.com/DjangoCRM/django-crm/discussions){target="_blank"}.
Haga preguntas, comparta ideas u obtenga ayuda de otros usuarios y colaboradores.
Nuestro equipo y colaboradores de la comunidad brindan soporte para:

* Instalación y configuración inicial de Django CRM.
* Solución de problemas técnicos y corrección de errores.

También puede examinar [GitHub Issues](https://github.com/DjangoCRM/django-crm/issues){target="_blank"} para ver si su pregunta ya ha sido respondida o para reportar un error.

## 📖 **Documentación**

Nuestra [documentación oficial](documentation.md) incluye instrucciones de configuración, descripción general de funciones y consejos para comenzar.
Es un excelente primer paso para resolver la mayoría de los problemas.

## 🛠 **¿Necesita Ayuda con la Personalización?**

Django CRM está diseñado para ser flexible y extensible:

* Personalización de módulos y flujos de trabajo para satisfacer sus necesidades comerciales.
* Integración con servicios de correo electrónico, herramientas de terceros y sistemas externos.

Si busca ayuda con funciones personalizadas o integración, le recomendamos que se comunique a través de la comunidad o
busque desarrolladores de Django experimentados familiarizados con proyectos de código abierto.

## 🤝 **Contribuir**

¿Encontró un error? ¿Desea sugerir una nueva característica? Abra un issue o envíe un pull request en
[GitHub](https://github.com/DjangoCRM/django-crm){target="_blank"}. Las contribuciones siempre son bienvenidas.
