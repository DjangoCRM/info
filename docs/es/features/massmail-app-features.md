# Aumenta la eficiencia de ventas con marketing por correo integrado: envía campañas personalizadas directamente desde el CRM

La **aplicación Massmail** es una función integrada del CRM que permite a tu equipo gestionar y enviar campañas de correo. Está diseñada para los gerentes de ventas que necesitan comunicarse con leads, contactos y empresas de manera eficiente, sin salir de su flujo de trabajo.

## Diseñado para outreach basado en CRM

Massmail funciona dentro de los datos existentes de tu CRM. Puedes enviar correos a contactos ya registrados en el sistema utilizando tu cuenta de correo asignada. Cada gerente de ventas solo tiene acceso a sus destinatarios y puede utilizar únicamente las cuentas de correo vinculadas a su perfil.

Massmail requiere:

* Una lista de destinatarios en la base de datos del CRM
* Cuentas de correo marcadas para envío masivo

Para proteger la entregabilidad, los correos enviados desde la cuenta principal del gerente de ventas solo se envían a destinatarios VIP.

## Control y flexibilidad

Puedes elegir cómo crear tu lista de correo:

* **Método rápido**: selecciona destinatarios desde cualquier vista de lista (por ejemplo, empresas o leads) y crea un envío directamente desde el menú de acciones.
* **Método avanzado**: utiliza el botón “Create Mailing” para aplicar filtros y generar una lista específica, ideal cuando trabajas con un gran número de registros.

También puedes definir horarios de envío para evitar entregas fuera de horario. Estos horarios son configurables.

## Mensajes personalizados

Massmail permite a tu equipo enviar mensajes que se sienten individuales, incluso a gran escala.

Antes de enviar una campaña, los gerentes de ventas preparan el contenido del mensaje y seleccionan una firma. Cada gerente puede mantener una biblioteca personal de firmas adaptadas a distintos escenarios, como prospección fría, seguimientos u ofertas especiales.

Para mejorar la participación, las plantillas de mensajes pueden incluir etiquetas dinámicas que insertan automáticamente los datos personales de cada destinatario. Esto te permite crear mensajes como:

### 📨 Plantilla de ejemplo

```
Hola {{ first_name }},

Hemos visto tu interés en nuestros servicios y queríamos seguir con algunas opciones adaptadas a ti.

```

### ✅ Cómo se ve al enviarse

```
Hola Emma,

Hemos visto tu interés en nuestros servicios y queríamos seguir con algunas opciones adaptadas a ti.

Saludos cordiales,  
John Smith  
Gerente de ventas
```

Estas etiquetas, como **{{ first_name }}**, **{{ last_name }}**, **{{ company }}** y otras, se reemplazan con datos reales extraídos directamente de tu CRM. Esto ahorra tiempo y garantiza que cada mensaje se sienta relevante y personalizado.

Cada mensaje también incluye un enlace de baja, lo que te ayuda a cumplir con las normas de comunicación y ofrece a los destinatarios control total sobre sus preferencias.

### Seguimiento de respuestas en el software CRM

Para reducir el ruido, el software CRM importa automáticamente solo los correos vinculados a solicitudes comerciales y acuerdos, que están organizados mediante un sistema de tickets. Si un destinatario responde a un boletín con una consulta comercial, ese mensaje puede importarse manualmente con un clic y el resto del hilo se seguirá automáticamente.

El sistema también admite OAuth 2.0, por lo que puedes conectar cuentas que requieran autenticación en dos pasos.
